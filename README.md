# 성적 관리 프로그램 (ai-programming-week11)

## ① 무엇을 하나요 (What)

성적 CSV 파일을 읽어 0~100점 범위의 유효한 `(이름, 점수)` 목록과 규칙에 맞지 않아 건너뛴 줄의 `(줄번호, 원본줄, 이유)` 기록을 나누어 반환합니다.

## ② 왜 만들었나요 (Why)

실제 성적 파일에는 빈 칸, 정수가 아닌 문자열(`결석`), 0~100점을 벗어난 점수(`105`, `-5`), 열 개수가 다른 줄이 섞여 있어 단순 파싱 코드는 실행 중 멈추거나 잘못된 점수를 조용히 통과시킵니다. 잘못된 줄 때문에 전체 처리가 중단되지 않게 하면서도 무엇이 왜 제외되었는지 투명하게 확인하고, 이를 `pytest` 자동화 테스트로 반복 검증하기 위해 만들었습니다.

## ③ 어떻게 쓰나요 (How)

```bash
# 설치
pip install pytest pytest-cov

# 실행
python3 load_scores.py scores.csv
```

## ④ 어떻게 테스트하나요

```bash
pytest test_load_scores.py --cov=load_scores --cov-report=term-missing
```

## ⑤ 파일 구성

| 파일 | 하는 일 |
| --- | --- |
| `load_scores.py` | 성적 CSV를 읽어 `(유효 목록, 건너뛴 줄 기록)`을 반환하는 메인 모듈 |
| `test_load_scores.py` | 명세서 설계표(정상·예외·경계값)를 바탕으로 직접 작성한 `pytest` 테스트 |
| `test_ai_A.py` | 프롬프트 A(코드를 제공)로 생성한 AI 단위 테스트 |
| `test_ai_B.py` | 프롬프트 B(명세만 제공)로 생성한 AI 단위 테스트 |
| `test_ai_bug.py` | 고장 난 `bug3_logic.py`를 주었을 때 버그를 정답으로 굳히는 함정 실험 테스트 |
| `scores.csv`, `empty.csv`, `weird.csv` | 정상·빈 파일·이상값 검증용 CSV 데이터 |
| `bug3_logic.py`, `prompts.txt` | 8주차 논리 버그 실험 파일 및 A/B 프롬프트 원문 |

## ⑥ 만든 사람 · AI를 어디에 썼는지

- 만든 사람 : 미래융합학부 2026100097 김태균
- AI를 쓴 곳 : 프롬프트 A(`test_ai_A.py`)·프롬프트 B(`test_ai_B.py`)·함정(`test_ai_bug.py`) 비교 실험용 테스트 생성 및 `pytest` 문법 확인
- 내가 직접 판단한 것 : 코드를 보지 않고 명세서 6칸만으로 8개 테스트 케이스(정상·예외·경계값 `-1, 0, 1, 99, 100, 101`)를 설계한 것, 커버리지 미실행 줄(`55-56행`, `77-86행`)의 원인을 분석해 빈 이름 케이스를 보강한 것, AI가 만든 테스트에서 버그 고착(`== 85`) 여부를 판정한 것
